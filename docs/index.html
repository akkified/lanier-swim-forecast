    How this works

    Chattahoochee Riverkeeper tests Lake Lanier beaches once a week during swim season. Between tests, conditions can change fast. This site uses a machine learning model trained on past Riverkeeper samples, along with rainfall, temperature, river flow, and lake level, to estimate the risk on days nobody is testing.

    The swim limit is 235 E. coli per 100 mL, the EPA single sample level that Swim Guide uses. Risk levels compare each day to how the model scored past high days.
